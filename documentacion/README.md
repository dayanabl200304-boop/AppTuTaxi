# Documentación del proyecto AppTuTaxi

Esta carpeta contiene la documentación técnica y funcional del proyecto AppTuTaxi, desarrollado como parte del proceso formativo del SENA en el programa Análisis y Desarrollo de Software.

## Documentos del proyecto

- Manual técnico del sistema.
- Manual de usuario.
- Guía de instalación y configuración.
- Documentación de la arquitectura del software.
- Casos de prueba y resultados.
- Informes de pruebas funcionales.
- Documentación del despliegue del sitio web.
- Evidencias del desarrollo del proyecto.

## Objetivo

Organizar y mantener disponible la documentación necesaria para comprender, instalar, utilizar, probar y realizar el mantenimiento de AppTuTaxi.
